# 🛠️ WinTune Optimizer Pro

A modern, open-source Windows optimization tool built with C# and WinForms.

## ✨ Features
- **Privacy Protection:** Disables Windows ads, telemetry, and Copilot.
- **Bloatware Cleaner:** Safely removes unnecessary built-in apps (Xbox, Skype, Maps, etc.).
- **System Tweaks:** Brings back the classic context menu and left-aligns the taskbar.
- **Restore Defaults:** Reverts all changes back to Windows factory settings.
- **Live Console Log:** Shows real-time feedback of background PowerShell processes.

## 🚀 How to Use
1. Download the latest `WinTune.exe` from the **Releases** section.
2. Run the application as Administrator (Required).
3. Select the optimizations you want and click to apply.

## ⚠️ Disclaimer
This tool modifies Windows Registry settings. Use it at your own risk. Always create a restore point before making system changes.
